# תערוכת בינה מלאכותית — כיתה ח׳1, כוכב השחר

אתר סטטי לפרסום ב־GitHub וב־Vercel. אין צורך ב־npm, בבנייה או בשרת.

## העלאה
1. צרו Repository חדש ב־GitHub או העלו לפרויקט קיים.
2. העלו את **תכולת התיקייה** (`index.html` ותיקיית `projects/`) לשורש המאגר, לא את ה־ZIP עצמו.
3. ב־Vercel בחרו Add New → Project, ייבאו את המאגר, הגדירו Framework Preset כ־Other ו־Root Directory כ־`./`, ופרסמו.

## הוספת עבודות
העתיקו את קובץ ה־HTML ל־`projects/`, והוסיפו אובייקט חדש למערך `projects` שבתחתית `index.html`.

## מגבלות
עבודות התלמידים נשמרו כפי שהועלו, למעט תיקון עיצוב טקסט קל במשחק האבירים. תלויות Tailwind CDN/Google Fonts/Font Awesome ותמונות מרוחקות דורשות רשת. מדובר בדוגמאות לימודיות, לא בשירותי מסחר/פיננסים/אבטחת מידע אמיתיים. קובץ `audit-report.json` מפרט בדיקות תחביר סטטיות.
